# Automatizacion_reporte 

En la era digital, cada vez tenemos actividades más repetitivas que nos consumen tiempo, energía y que consecuentemente nos lleva a reducir la productividad y el tiempo que puede emplearse en otras asignaciones. Debido a ello, la automatización de reportes y de documentos permite agilizar estos procesos; desarrollando un proceso que facilite el envio de documentos y otros.
